## 可运行交付

React 19 + TypeScript + Vite + Recharts + Lucide，FastAPI + Pydantic，SQLite标准库。生产同源服务于127.0.0.1:8000；无云部署与付费服务。依赖锁、API契约、模拟数据、公式、脚本、README与验收证据均在项目内。6角色按1→3→2→4→5→6串行完成，详见ROLE_HANDOFFS.md。

实际使用 `python scripts\start.py` 完成依赖检查、构建并启动生产服务，首页及风险汇总HTTP200。`start.cmd`为该命令的Windows入口。已有依赖和构建时`python scripts\start.py --no-build`可离线使用。开发模式支持后端热重载及Vite同启；最终全链路验收针对生产模式。

6. 打印按钮调用浏览器标准打印，报告打印样式已实现；未实际向物理打印机输出。浏览器自动化环境仅本机Windows Edge，未覆盖Safari/Firefox与所有设备。
